# Agent Ledger Template

| ID | Date | Tool / model | Delegated task | AI proposal (summary) | Human decision | Verification | Evidence |
|----|------|--------------|----------------|----------------------|----------------|--------------|----------|
| E0000 | YYYY-MM-DD | … | … | … | accept / modify / reject / escalate | … | commit + run ID |

Rules:
- Log only interactions that can change scientific evidence.
- The human decision column is mandatory; never backfill a decision that was not actually made.
- Verification = what the human did to check the output (read, re-run, unit test, cross-check vs paper).
- Rejections must be genuine; never fabricate one to satisfy the rubric.
